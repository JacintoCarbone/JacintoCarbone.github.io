### Featured Repositories & Engineering Projects

1. **[`talos-3d-print-erp`](https://github.com/JacintoCarbone/talos-3d-print-erp)**  
   *Native Android ERP application built in **Kotlin & Jetpack Compose** with **Room SQLite** relational persistence to manage 3D printing farms and additive manufacturing businesses. Tracks filament spool inventory in real-time grams, production order states, parametric printing cost calculations, and financial cashflow.*

2. **[`avr-baremetal-micro-os`](https://github.com/JacintoCarbone/avr-baremetal-micro-os)**  
   *Pure C99 bare-metal operating core for AVR microcontrollers (`ATmega328P`). Direct register manipulation, interrupt-driven 64-byte circular buffer UART driver, 1ms Timer1 CTC hardware scheduler, interactive CLI parser, Wokwi simulation schematic, and Python Serial Host Bridge.*

3. **[`python-web-harvester`](https://github.com/JacintoCarbone/python-web-harvester)**  
   *Enterprise-grade Python web scraping and inventory monitoring pipeline. Features defensive HTTP client with exponential backoff retries, rate-limiting jitter, normalized extraction, and automated Excel-compatible CSV & JSON exports.*

4. **AI Camera-Based Chemical Formula Interpreter**  
   *Computer Vision & Machine Learning system developed at UTEC capable of capturing real-time camera feeds and optically recognizing/interpreting chemical formulas.*
